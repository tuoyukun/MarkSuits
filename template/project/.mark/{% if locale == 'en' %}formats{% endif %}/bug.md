# Format: bug.md

Written by the orchestrator with the human before the ticket opens; read only for every
role (fix-plan records what it finds in `fix-plan.md`). Lives in the ticket dir on main.

```markdown
# <id> · <title>

## Report
<the human's words, verbatim>

## Reproduction
1. <step>
2. <step>

## Expected
<what should happen instead>

## Impact
<who is affected, how often, how badly>
```

Unknown parts say "unknown"; fix-plan establishes them.
