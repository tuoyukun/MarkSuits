# 格式：bug.md

工单打开时及讨论期间由 orchestrator 和人一起写定；对所有角色只读（fix-plan 把查到的东西写进
`fix-plan.md`）。放在 main 上的工单目录里。

```markdown
# <编号> · <标题>

## 报告
<人的原话，逐字保留>

## 复现步骤
1. <步骤>
2. <步骤>

## 期望
<本应发生什么>

## 影响
<影响谁、多频繁、多严重>

## 已有调查
<开单前或讨论中已经查过什么、发现了什么：证据（报错、`文件:行号`、commit）、疑似或确认的根因、
已排除的路径。还没人查过就写「未知」。>
```

不清楚的部分写「未知」，由 fix-plan 查清。已有调查是线索，不是定论：fix-plan 负责核实或纠正。
